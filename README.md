# skills

Public agent skills from Zenchant Live.

This repo is the first public bundle of wiki-related skills extracted from Jordan's local Hermes setup so they can be shared, reused, and expanded over time.

## Current folders

### `wiki/`
The first published skill pack, focused on capture and knowledge workflows.

Included:
- `wiki/knowledge-wiki` — the compiled wiki substrate, page structure, linking, provenance, linting, and compile workflow
- `wiki/content-ingestion` — URL, YouTube, and local-file ingestion into the wiki raw-source pipeline

## Repo purpose

This repo is meant to become a clean public home for reusable agent skills.

Right now it ships the first wiki-focused set. More folders and skill packs can be added over time.

## Notes

These skills include their supporting files where applicable, including:
- `references/`
- `scripts/`
- `templates/`
- `examples/`
- `hooks/` (for `knowledge-wiki`)
